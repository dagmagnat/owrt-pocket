# Cudy WR300 v1 — OpenWrt 25.12.6 Pocket Full

Только **Cudy WR300 v1**, target `ramips/mt76x8`, уже работающий под OpenWrt.
Это `sysupgrade`, не универсальный файл для установки из заводской прошивки.
WR3000/WR3000H и другие ревизии не подходят.

Сборка: штатное ядро и ImageBuilder 25.12.6, русский LuCI/HTTPS, SSH, DHCP WAN,
PPPoE, Wi-Fi, WireGuard, AmneziaWG, owrt-pocket 0.2.0 и RouteWolf v59.
AmneziaWG поступает из подписанного feed проекта Slava-Shchipunov/awg-openwrt
для точной версии/target; APK проверяет зависимости и ABI ядра.

Полный исходный список RouteWolf включён, **не lite**. Валидные дубли и вложенные
CIDR сворачиваются без потери покрытия; ошибочные записи исключает v59.
В полном списке есть очень широкие `/7`–`/8`; здесь явно разрешён минимальный
префикс `/7`, чтобы не подменять выбранный полный профиль стандартным фильтром
шире `/16`. Это может направить большой объём трафика в VPN после его настройки.
Числа исходных и эффективных записей есть в `integration.json`, отказы — в
`list-validation.log`. IPv6 VPN не настроен; DNS AAAA фильтруется как в исходном
RouteWolf при отключённом IPv6-профиле.

Удалены коллекции LuCI с пакетным менеджером/attended sysupgrade и их отдельные
веб-модули. Сохранён лёгкий LuCI с основными страницами, firewall, HTTPS и русский
перевод. Сам apk, SSH и необходимые сетевые компоненты остаются.

## Первый запуск

- Wi-Fi: **Cudy_WR-300**, **открытая сеть без пароля**.
- Пользователь: **root**, **пароль пустой** — по явному запросу владельца.
- Любой подключившийся к LAN/Wi-Fi может управлять устройством. WAN-управление
  закрывается штатным firewall. Это конфигурация для контролируемого испытания.
- LAN ожидается штатный `192.168.1.1`; WAN получает DHCP. PPPoE: `owp internet`
  или LuCI → Network → Interfaces → WAN.
- Wi-Fi включён при первом запуске и загрузке; отключение через `owp` защищено
  профилем. Ручная настройка LuCI/UCI и аппаратные/драйверные сбои всё ещё могут
  его выключить — постоянного демона принудительного включения нет.
- Регион не указан владельцем: world `00`, канал 6, HT20. Канал/ширину менять
  после проверки эфира и установки корректной страны для своего местоположения.

## VPN и RouteWolf

Ключей VPN в образе нет. В LuCI подготовлены выключенные интерфейсы `wg0` и
`awg0`. Внесите свой адрес/ключ/peer/endpoint, оставьте **Route Allowed IPs
выключенным**, чтобы общий маршрут остался через провайдера. Затем:

```sh
rw-setup wg0     # или rw-setup awg0, подтверждение Yes
rw status
rw diag
rw lists report
```

`rw-setup off` выключает выборочную маршрутизацию; VPN-интерфейсы/ключи сохраняет.
Обычный интернет работает до настройки VPN. Доступность конкретных VPN-серверов
и реальная скорость не проверены. Для управления роутером по дополнительному WG
нужны отдельные правила доступа — эта будущая настройка не включена.

Ночные проверки: списки 02:00, код 03:00 по времени роутера. Стандартный updater
RouteWolf требует 2 МиБ свободной flash; на 8-МБ устройстве он может отложить
обновление, и это ограничение не обходится. На полном списке actual RAM/CPU и
работу 10–30 клиентов нужно измерить. Дополнительные DNS/VPN-движки, статистика,
фоновые speedtest и тяжёлые сканеры не включены.

## Перед установкой

Сохраните резервную копию вне роутера, проверьте модель и SHA256SUMS. Для первого
испытания нужен LAN-кабель и известный способ восстановления именно WR300 v1.
Рекомендуется чистая установка без сохранения старых настроек: иначе прежние
настройки могут перекрыть язык/Wi-Fi/сети этого профиля. Файл здесь не прошивается
автоматически; установку выполняет владелец после проверки.

Сборочные проверки: подписи пакетов, ABI solver, состав rootfs, метаданные модели,
размер и SHA-256. **Загрузка на реальном WR300 v1, свободная RAM и пропускная
способность ещё не испытаны.** `verification.json` содержит оценку запаса по
размеру раздела; это не измерение свободного JFFS2 после загрузки.
